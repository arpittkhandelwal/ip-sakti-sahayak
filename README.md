## Quick Start

```bash
# 1. Clone and install
git clone <your-repo>
cd ip-sakti-sahayak
npm install

# 2. Configure environment
cp .env.example .env
# Edit .env and add your SARVAM_API_KEY

# 3. Build the BM25 search index from corpus
npm run ingest

# 4. Start local dev server (Vite + Netlify Functions)
netlify dev
# → Frontend: http://localhost:5173
# → Functions: http://localhost:8888

# 5. Open browser at http://localhost:8888
```

## Local Development

### Prerequisites

- Node.js 18+ (`node -v`)
- Netlify CLI (`npm install -g netlify-cli`)
- Sarvam AI API key (get one at [sarvam.ai](https://sarvam.ai))

### Setup

```bash
npm install
cp .env.example .env
# Add SARVAM_API_KEY to .env

npm run ingest         # Build BM25 index
netlify dev            # Start dev server
```

### Development Workflow

```bash
# TypeScript check
npm run typecheck

# Add new corpus files, then rebuild index
npm run ingest

# Run evaluation (requires running server)
npm run eval
```

### API Endpoints (Netlify Functions)

| Endpoint | Method | Description |
|---|---|---|
| `POST /api/prepare` | POST | Detect lang, translate, classify, retrieve |
| `POST /api/answer` | POST | Generate grounded answer, verify, confidence |
| `POST /api/localize` | POST | Translate answer to user language |
| `POST /api/voice` | POST | STT/TTS (requires `VITE_ENABLE_VOICE=true`) |

## Deploy to Netlify

### Method 1: GitHub Integration (Recommended)

1. Push your code to GitHub
2. Go to [netlify.com](https://netlify.com) → "Add new site" → "Import from Git"
3. Connect your GitHub repo
4. Build settings (auto-detected from `netlify.toml`):
   - Build command: `npm run ingest && npm run build`
   - Publish directory: `dist`
   - Functions directory: `netlify/functions`
5. Add environment variables (see [Environment Variables](#environment-variables))
6. Click "Deploy site"

### Method 2: Netlify CLI

```bash
netlify login
netlify init
netlify env:set SARVAM_API_KEY your_key_here
netlify env:set SARVAM_CHAT_MODEL sarvam-m
netlify deploy --build --prod
```

## Environment Variables

Set these in Netlify Dashboard → Site settings → Environment variables:

| Variable | Required | Default | Description |
|---|---|---|---|
| `SARVAM_API_KEY` | ✅ Yes | — | Your Sarvam AI subscription key |
| `SARVAM_CHAT_MODEL` | No | `sarvam-m` | Chat model name |
| `SARVAM_TRANSLATE_MODEL` | No | `mayura:v1` | Translation model |
| `SARVAM_STT_MODEL` | No | `saarika:v2` | Speech-to-text model |
| `SARVAM_TTS_MODEL` | No | `bulbul:v1` | Text-to-speech model |
| `VITE_ENABLE_VOICE` | No | `false` | Enable voice features |
| `VITE_ENABLE_LLM_RERANK` | No | `false` | Enable LLM-based reranking |
| `TOP_K` | No | `5` | Max BM25 results |
| `MIN_SCORE_THRESHOLD` | No | `0.5` | Min confidence for non-abstention |
| `RATE_LIMIT_RPM` | No | `20` | Requests per minute per IP |
| `INPUT_MAX_CHARS` | No | `2000` | Max query length |

> **Security**: Never expose `SARVAM_API_KEY` to the frontend. All API calls go through Netlify Functions.

## Adding Real Corpus Content

The app ships with **sample files** marked `sample: true`. To add real legal texts:

1. Read `CORPUS_GUIDE.md` for the exact frontmatter schema
2. Create `.md` files in the appropriate corpus subdirectory
3. Source text from official primary sources only (see CORPUS_GUIDE.md for URLs)
4. Run `npm run ingest` to rebuild the index
5. The "Sample Corpus" banner will disappear automatically

## Running Evaluation

The evaluation harness requires a running local server:

```bash
# Terminal 1: Start the server
netlify dev

# Terminal 2: Run evaluation
npm run eval
```

This generates:
- `eval/results.md` – Summary + per-question results
- `eval/results.csv` – Machine-readable results

**What is evaluated:**
- LLM-as-judge accuracy (0-10 rubric) vs no-RAG baseline
- Citation precision and recall
- Retrieval Recall@k and MRR
- Abstention accuracy (should it refuse? did it?)
- Multilingual quality (back-translate and re-judge)

## Troubleshooting

### `npm run ingest` fails: "No markdown files found"
- Check that corpus directory exists and contains `.md` files
- Verify frontmatter format matches CORPUS_GUIDE.md schema

### Netlify Function timeout (10s)
- The pipeline is split into 3 separate functions (`/api/prepare`, `/api/answer`, `/api/localize`) to stay under the 10-second limit
- If still timing out: reduce `TOP_K` to 3, or disable LLM rerank (`VITE_ENABLE_LLM_RERANK=false`)
- Consider upgrading to Netlify Pro for 26-second timeout

### Sarvam API 429 (Rate Limited)
- The Sarvam client has built-in retry with backoff (500ms, 1.5s, 4s)
- Reduce `RATE_LIMIT_RPM` to protect your quota
- Check your Sarvam API subscription tier limits

### `index.json` too large (> 25MB Netlify limit)
- Keep individual chunks under 2000 characters
- Split large documents into smaller sections with more headings
- Use the `section_or_article` frontmatter to create logical split points

### Sarvam model names changed
- All model names are in `.env` and default to env vars in `src/lib/sarvam.ts`
- Update the env var in Netlify dashboard; no code changes needed
- Cross-reference at [docs.sarvam.ai](https://docs.sarvam.ai)

### Translation breaks legal terms
- The `protectLegalTerms()` function in `sarvam.ts` uses placeholder substitution
- Add patterns for any legal terms that are being mistranslated
- Statute names, section numbers, URLs, and citation IDs are always protected

## Architecture

```
User Query
    │
    ▼ (browser)
┌─────────────────────────────────────────────────┐
│                 React Frontend                   │
│  Language Selector · Jurisdiction Toggle         │
│  Chat Panel · Classifier Sidebar                 │
│  Citation Cards · ABS Checklist · Confidence     │
└──────────┬────────────────────────────────────────┘
           │ 3 sequential API calls
           ▼
┌──────────────────────────────────────────────────┐
│          /api/prepare (Netlify Function)         │
│  1. Detect language (Sarvam LID + heuristic)     │
│  2. Translate query to English (Sarvam Translate)│
│  3. Classification state machine (LLM JSON)      │
│  4. BM25 retrieval (MiniSearch, top-k=5)        │
│  5. Metadata filter (jurisdiction, ip_type)      │
│  6. Lightweight rerank (term coverage + phrase)  │
└──────────┬───────────────────────────────────────┘
           │
           ▼
┌──────────────────────────────────────────────────┐
│          /api/answer (Netlify Function)          │
│  1. Optional LLM rerank (top-8 → top-4, flagged)│
│  2. Generate answer (Sarvam chat, grounded only) │
│  3. Prompt injection guard (retrieved text=DATA) │
│  4. Citation verifier (strip unverified refs)    │
│  5. Confidence scorer (BM25 scores + coverage)  │
│  6. ABS checklist + TKDL pointers (if relevant) │
│  7. Safe abstention (below threshold)            │
└──────────┬───────────────────────────────────────┘
           │
           ▼
┌──────────────────────────────────────────────────┐
│          /api/localize (Netlify Function)        │
│  1. Protect legal terms (placeholder map)        │
│  2. Translate answer (Sarvam Translate)          │
│  3. Restore legal terms                          │
└──────────┬───────────────────────────────────────┘
           │
           ▼ Localized answer, citations, confidence
        Browser renders response
```

**BM25 Index**: Built at deploy time by `npm run ingest`, loaded once at module scope in each Netlify function (cold start). No embeddings API needed.

**Safety properties**:
- All Sarvam API calls server-side only
- Retrieved text is explicitly marked DATA (prompt injection guard)
- Citation verifier strips unverified references
- Confidence is computed from BM25 scores (not LLM self-report)
- Anonymized audit log (query hash only, no PII)
- Rate limiting per IP, input length cap
